# 🛒 E-Commerce Sales Analytics Dashboard

## 📌 Project Overview

This is an end-to-end Data Analytics project that analyzes e-commerce sales data to uncover valuable business insights related to sales performance, customer behavior, product trends, and profitability.

The project demonstrates the complete analytics workflow from data cleaning and transformation to data analysis and dashboard development using Excel, SQL, Power BI, and Tableau.

---

## 🎯 Business Objectives

The main objectives of this project were:

- Analyze overall sales and profit performance
- Identify top-performing products and categories
- Understand customer purchasing behavior
- Track regional sales performance
- Monitor key business KPIs
- Support data-driven business decision making

## 📂 Project Workflow

### 1. Data Collection

- Imported raw e-commerce sales dataset
- Reviewed dataset structure and data quality

### 2. Data Cleaning & Preparation

- Removed duplicate records
- Handled missing values
- Standardized data formats
- Verified data consistency

### 3. SQL Data Analysis

- Created and managed database tables
- Wrote SQL queries for business analysis
- Performed aggregations and KPI calculations
- Extracted actionable business insights

### 4. Power BI Dashboard Development

Created interactive dashboards to analyze:

- Total Sales
- Total Profit
- Sales Trends
- Product Performance
- Customer Analysis
- Regional Analysis

### 5. Tableau Dashboard Development

Built interactive visualizations featuring:

- KPI Cards
- Dynamic Filters
- Sales Trends
- Customer Insights
- Product Analysis
- Regional Performance
